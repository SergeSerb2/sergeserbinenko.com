[T3 Code](https://github.com/pingdotgg/t3code) is an open-source app for running coding agents, made by the team at ping.gg. T3 Pretty is my fork of it. I work in it every day, and this site was built in it.

I keep the fork in sync with upstream and build on top. So far that is about 1,800 commits of my own.

## World Scenery

Every thread sits in front of a full-bleed photo of a real place, credited to its photographer. The interface floats over it on frosted glass. There are five photo sets: World Scenery, Night Cities, Deep Forest, Night Sky, and Grand Buildings. The glass follows your light or dark setting, never the photo, so text stays readable on any scene.

This website borrows the same idea.

## Built for long agent sessions

- A **Stored** shelf for long-running threads, across the server, the web app, and iOS.
- A project rail with folders, drag to reorder, and live thread counts.
- Threads grouped by pull request, with a live count of running subagents on each row.
- Native Linear and Sentry issue management.
- Agents can ask for an API key through a masked prompt, so secrets never go into the chat.
- Voice input, secrets, and folders shared across connected machines.

## On the phone

A companion iPhone app floats the same frosted surfaces over the same scenery, with the photo catalog synced between devices.
