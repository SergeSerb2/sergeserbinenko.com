[AeroSpace](https://github.com/nikitabobko/AeroSpace) is a tiling window manager for macOS that you drive entirely from the keyboard. The shortcuts are the hard part, so I made a Duolingo-style course for them.

- **Path:** 10 units and 23 lessons, from focus and move to layouts, workspaces, and service mode.
- **Review:** spaced repetition of the shortcuts you have already seen.
- **Free fly:** a fake tiled desktop that obeys the default key map, so you can practise for real.
- **Book:** a searchable cheatsheet.

In fullscreen, it locks the keyboard so chords like Cmd+W reach the lesson instead of the browser.
